# AI 视频 · 图片提示词数据库

一个可直接在浏览器中运行的 AI 提示词管理器。主页分别提供视频提示词和图片提示词的导入、整理与导出入口。

## 在线功能

- 分别导入、管理和导出视频提示词与图片提示词；
- 导入 TXT、Markdown 和 JSON，支持多文件批量导入；
- 视频提示词自动识别分类、画幅、时长、分辨率、标签和时间码分镜；
- 图片提示词自动识别肖像、产品摄影、概念设计、插画、海报等分类；
- 独立建立、重命名和删除合集，按媒介、关键词、分类、画幅和合集组合筛选；
- 编辑、归档和删除提示词；
- 分别导出视频 JSON 备份与图片 JSON 备份，互不混入；
- 使用 IndexedDB 在当前浏览器中即时持久化。

## 数据存储说明

GitHub Pages 是静态网站。导入或编辑的数据会实时保存在当前浏览器，不会自动提交回 GitHub 仓库，也不会跨浏览器或跨设备同步。

更换设备或清理浏览器数据前，请分别点击“视频 → 导出”和“图片 → 导出”。在新设备上从对应入口重新导入备份 JSON 即可恢复。

## 本地运行

直接打开 `index.html`，或者双击 Windows 下的 `启动数据库.bat`。

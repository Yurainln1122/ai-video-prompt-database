# AI 视频提示词数据库

一个可直接在浏览器中运行的 AI 视频提示词管理器，支持提示词搜索、批量导入、自动分类、分镜提取、编辑整理和 JSON 备份。

## 在线功能

- 导入 TXT、Markdown 和 JSON；
- 自动识别分类、画幅、时长、分辨率、标签和时间码分镜；
- 按关键词、分类、画幅和合集筛选；
- 编辑、归档和删除提示词；
- 导出完整 JSON 备份；
- 使用 IndexedDB 在当前浏览器中即时持久化。

## 数据存储说明

GitHub Pages 是静态网站。导入或编辑的数据会实时保存在当前浏览器，不会自动提交回 GitHub 仓库，也不会跨浏览器或跨设备同步。

更换设备或清理浏览器数据前，请在页面右上角点击“导出备份”。在新设备上把备份 JSON 重新导入即可恢复。

## 本地运行

直接打开 `index.html`，或者双击 Windows 下的 `启动数据库.bat`。
